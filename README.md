# php-mini-project-advisories

Public security advisories for freely distributed PHP mini-projects,
published as part of coordinated disclosure. Each file documents one
vulnerability: root cause with file and line references, non-weaponized
proof, classification (CWE, CVSS), deduplication status and a suggested fix.

| Advisory | Product | Class |
|---|---|---|
| A1-pos-pharmacy-login-sqli.md | code-projects POS Pharmacy System 1.0 | SQL Injection (CWE-89) |
| A2-pos-pharmacy-missing-auth.md | code-projects POS Pharmacy System 1.0 | Missing Authorization (CWE-862) |
| B1-hotel-reservation-missing-auth.md | Campcodes Online Hotel Reservation System 1.0 | Missing Authorization (CWE-862) |

Vendors were contacted on 2026-11-10. Entries were checked against NVD and
the VulDB database prior to publication; dedup status is stated per file.
